## Investigation Framework

One framework I consistently practice throughout these lessons:

1. Clarify the business question.
2. Validate the data.
3. Identify the KPI driver.
4. Segment the affected population.
5. Form hypotheses.
6. Recommend actions.

The goal is to think like a Senior Data Analyst rather than simply write SQL.
